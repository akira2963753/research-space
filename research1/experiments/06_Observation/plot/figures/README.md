# Drop-rate figures

DEWA drop rate of normal partial sums versus `T_drop` (`T_replace = 3`), with and without
activation-outlier separation, on LLaMA2-7B W-BFP4 / G16 (224 decoder Linear layers).

- `g16/drop_rate_vs_tdrop`: log-scale drop rate for `T_drop = 4..10`; the dotted line marks the
  `T_drop = 9` design point.
- Each figure is stored as a 600-DPI PNG and a same-stem vector PDF.
- Outputs are regenerated by `../plot_drop_rate.py` from
  `../../llama2-7b/*-blkexp-runmax-*.json`.
