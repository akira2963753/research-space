# Exponent-profile figures

This directory contains the active BFP partial-sum exponent-profile figures.

- `g16/`: Group-16 results.
- `g32/`: Group-32 results.
- Each active figure is stored as a 600-DPI PNG and a same-stem vector PDF.
- Outputs are regenerated by `../plot_exponent_profile.py` with the matching
  `--group-size` value.

The full-span heatmaps use vector mesh cells in the PDF export; they are not
PNG images embedded into PDF files.
