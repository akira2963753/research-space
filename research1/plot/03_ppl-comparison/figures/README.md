# PPL-comparison figures

Active Group-16 figures are in `g16/`. Each active figure has a 600-DPI PNG
and a same-stem vector PDF regenerated by its corresponding script:

- `ppl_delta_comparison.*` and `ppl_delta_comparison_with_hybrid.*`:
  `../plot_ppl_comparison.py`
- `symmetric_asymmetric_treplace_ppl.*`: `../plot_asymmetric_treplace.py`
- `hybrid_symmetric_ppl_log_zoom_t3-12.*`:
  `../plot_hybrid_symmetric_ppl_log.py`
- `hybrid_asymmetric_tskip9_delta_ppl.*`:
  `../plot_hybrid_asymmetric_tskip9_ppl.py`
- `hybrid_tskip_treplace_delta_ppl.*`:
  `../plot_hybrid_tskip_treplace_ppl.py`

The four-model Vanilla-BFP comparisons are in `g16_g32/`:

- `vanilla_bfp_delta_ppl_g16.*` and `vanilla_bfp_delta_ppl_g32.*`:
  `../plot_vanilla_bfp_g16_g32.py`

The following retained PNGs are legacy snapshots rather than current outputs:

- `asymmetric_treplace_ppl.png`: no active script reproduces this older plot.

It remains in place to avoid breaking older references and intentionally does
not receive a synthetic raster-in-PDF conversion.
